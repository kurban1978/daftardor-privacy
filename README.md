# Daftardor — Privacy Policy

«Дафтардор» (`uz.kurban.daftardor`) иловасининг махфийлик сиёсати.
Уч тилда: ўзбекча, русча, инглизча.

Саҳифа GitHub Pages орқали чоп этилади:
**https://kurban1978.github.io/daftardor-privacy/**

Айнан шу манзил Google Play Console'да «Privacy policy URL» майдонига
киритилади.

## Нима учун алоҳида репозиторий

Илова коди хусусий (private) репозиторийда. GitHub Pages хусусий
репозиторийларда фақат тўловли режада ишлайди, шунинг учун сиёсат
саҳифаси алоҳида **очиқ** репозиторийда туради. Илова коди очилмайди.

## Янгилаш

Илова имкониятлари ўзгарса (масалан булут синхронизацияси ёқилса):

1. `index.html` даги учала тил бўлимини ҳам таҳрирланг
2. Ҳар бўлимнинг бошидаги санани янгиланг
3. Commit + push — GitHub Pages бир неча дақиқада ўзи янгиланади

⚠️ Play Console'даги декларациялар (Data safety) билан бу матн
**бир-бирига мос** бўлиши шарт. Мос келмаса илова рад қилинади.
